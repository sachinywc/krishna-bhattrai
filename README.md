# Jungle Heaven Works - Krishna Bhattari

A modern, minimalist portfolio website for wildlife conservationist and eco-tourism expert Krishna Bhattari, showcasing his work in Nepal's Bardia National Park.

## 🌿 About

This website represents Krishna Bhattari's 12+ years of experience in:
- **Eco-Hospitality** through Jungle Heaven
- **Tiger Conservation** in Tiger Country
- **Wildlife Photography & Research**
- **Sustainable Tourism Advocacy**
- **Indigenous Tharu Culture Integration**

## 🚀 Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** [Netlify](https://www.netlify.com/)
